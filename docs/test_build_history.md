## 운영 규칙

- 앞으로 사용자가 `테스트버전 만들어줘`, `testN 만들어줘`, `컴파일해줘`라고 요청하면:
  - 직전 테스트 빌드 이후 변경된 파일 목록을 먼저 확인
  - 수정 파일 원본은 `artifacts/test-build-backups/...` 아래에 복사 백업
  - 이 문서에 변경 파일과 요약 내용을 추가
  - 그 다음 테스트 설치파일을 생성
- 별도 소스 수정 없이 다시 컴파일만 한 경우에도:
  - `변경 파일 없음`
  - `재컴파일만 진행`
  - 으로 명시해서 남김

## 수정 파일 백업 위치

- 백업 스크립트: `Compile/Backup-TestWorkingSet.ps1`
- 테스트 빌드 스크립트: `Compile/Build-TestVersion.ps1`
- 백업 저장 폴더: `artifacts/test-build-backups/<timestamp>_<version>_<test-label>/`
- 백업 내용:
  - 실제 수정 파일 복사본
  - `manifest.json`
  - `changed-files.txt`
