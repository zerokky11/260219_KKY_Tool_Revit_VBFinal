Family Browser Path

Use this tab to prepare the family-browser/bootstrap.json file read by Family Browser clients.

Protected settings

Enter the page password to view and edit the Family Browser bootstrap settings.

This is a static page. It can save through the GitHub API only when you enter a GitHub token. Without a token, download the generated file and upload it to /family-browser/bootstrap.json.
Bootstrap profiles

Multiple JSON profiles can live under /family-browser. Users follow bootstrap-index.json automatically.

This is the central policy path every installed PC will use.

One path per line. Family Browser uses the first path that can be reached on this PC.
